# Microsoft product icons

Official icons from Microsoft's published icon packs, unmodified:

| File                                                                                      | Pack                                                                                                                          |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| business-central.svg, dynamics-365.svg                                                    | [Dynamics 365 icons](https://learn.microsoft.com/dynamics365/get-started/icons)                                               |
| power-platform.svg, power-apps.svg, power-automate.svg, dataverse.svg, copilot-studio.svg | [Power Platform icons](https://learn.microsoft.com/power-platform/guidance/icons)                                             |
| azure-devops.svg, azure-portal.svg (Azure-A, the current Azure logo)                      | [Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/) V24, `other/10018-icon-service-Azure-A.svg` |
| entra-id.svg                                                                              | [Microsoft Entra architecture icons](https://learn.microsoft.com/entra/architecture/architecture-icons) (Oct 2023)            |
| power-bi.svg (power_bi_24_color)                                                          | [Microsoft Fabric icons](https://learn.microsoft.com/fabric/fundamentals/icons) v6.1.0                                        |

Microsoft's terms for these packs permit use in architectural diagrams,
training materials and documentation. Using them in the extension's UI is
outside that; it was a deliberate choice for the beta (see the trademark
notice in store/listing). Don't crop, recolour or distort them, and don't use
them to represent Dynamic Assist itself. The Entra pack also asks that its
icons not be used in marketing communications.

Teams, Exchange and Microsoft 365 are not in these packs; see below.
